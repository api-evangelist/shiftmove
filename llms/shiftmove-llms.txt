# Shiftmove (Avrios Fleet-API)

> Shiftmove GmbH (Berlin) is a European fleet management software company, backed by Battery Ventures, operating the Vimcar, Fleet, Avrios, Optimum and Océan brands. Its developer surface is the Avrios Fleet-API, which syncs fleet data — vehicles, drivers, assignments, license plates, financing, usages, invoices and custom fields — with the Avrios/Shiftmove platform. HTTP Basic auth, 300 requests/minute, Swagger 2.0.

## API

- [Avrios Fleet-API reference (Redoc)](https://developers.avrios.com/): 40 operations across vehicles, drivers, assignments, invoices, organizations, custom fields, license plates, financing and usages. Base URL https://api.avrios.com, paths under /v1.
